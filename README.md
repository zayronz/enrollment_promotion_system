### 招生宣传报名平台建设

招生管理系统是建设智慧校园的重要攴撑部分，主要应用于各大髙校的招生管理部门，结合各学校招生的实际情况，招生管理系统拥有自动化的流程、智能的数据分析、科学的管理模式，有效改善了传统招生管理模式产生的管理效率较低，经营管理水平相对滞后等现象。

- **助力教学招生**

为适应教育改革的新形势，进一步加大学校招生宣传工作的力度，加强与生源中学的合作，组建稳定高效的招生宣传队伍，构建多渠道、全方位的招生宣传工作格局，提高招生宣传效果，保证招生宣传工作的制度化、系统化、规范化和常态化，不断巩固与提高学校本生源质量已经是教育发展趋势。

- **提高生源质量**

贯彻落实学校教育发展规划纲要，以提高生源质量为核心任务，强化组织领导，挖掘整合资源、拓宽宣传渠道、完善工作机制，按照国家、地方指导的工作方针，着手丰富和创新宣传方式，构建多渠道、多层次、全方位的招生宣传工作格局，助力教育事业更好地发展。

### 1.1 学生端

#### 1.1.1 登录

学生端的登录在统一身份认证基础上实现单点登录。实现同一套账号体系。其功能点如下：

- 登录：按照学校统一身份认证平台的账号体系，进行账号/密码登录，成功登录后，进入招生宣传报名系统；
- 忘记密码：在统一身份认证平台授权下，可进行密码找回；
- 修改密码：进行密码的修改。

#### 1.1.2 活动列表

由学校招生办创建的活动，按照系统设置规则，学生登录系统后，统会自动校验当前学生是否有报名该活动的资格，其资格条件设置是在活动创建时进行，如：绩点、成绩等。如该生不符合规则，则对应活动是不可见的。系统默认进入活动列表看到对自己开放可参与的活动。其功能点如下：

- 筛选查询：按照系统提供的筛选查询字段，可进行精准筛选查询活动；
- Banner(轮播图)：在活动列表界面，顶部进行轮播图的展示，点击可进入到对应的活动详情界面；
- 活动列表展示：活动列表展示将主要分为两大板块分类展示：线上活动和线下活动；
- 活动详情页：点击活动标题可进入到活动详情页，活动详情页构成可以由视频、图片、链接、文字和附件。对附件可进行下载；
- 活动报名：在活动创建时在详情页进行报名入口设置。学生进入详情页点击可进行当前活动的报名操作。同时系统会自动校验当前学生是否已报名该活动，如已报过名则关闭其报名功能。

#### 1.1.3 活动报名

系统开放多个报名入口，完全取决于活动创建者的创建活动时的设置，如活动列表页和活动详情页开放报名入口。学生在进行活动报名时主要进行相关信息的填写。系统会自动校验当前学生是否已报名该活动，如已报过名则关闭其报名功能。其功能点如下：

- 基本信息接口调取：学生的基本信息是当前登录用户在用户管理中去调用，保证信息的准确性和唯一性，同时也减少了学生的操作成本；
- 信息的填写上报：按照活动创建时设置的需填报信息，进行相关信息的填写，如招生活动中“招生对象学校”，需学生进行学校名称填写，填写后系统会对字段在技术上实现机械分词发和统计语言模型对学校类名称进行标准化（如两个学生填写的学校分别是：武汉理工大学和武汉理工，系统可自动进行对其规范，最终填报提交后，会统一为：武汉理工大学）；
- 信息自动同步选择填写：同样举学校填写学校信息为例，如果系统已经记录了该字段对应的部分信息即已有学生进行填报提交完成，那么当下一个学生进行填写时，系统进行模糊搜索匹配，如已有学生填写提交了“武汉理工大学”，当下一学生在填写该字段是输入：“武”、“武汉”等字段时，系统会自动将“武汉理工大学”悬浮至输入框下方供填写者便捷选择。
- 附件上传和下载：在进行报名时，可进行附件的上传和下载，附件支持PDF、word、excle等；

#### 1.1.4 已报名活动

 当学生进活动报名成功后，系统会自动生成当前学生的报名记录，在学生端，学生可进行相关信息的查看。

- 活动详情查看：可查看已报名活动的活动详情；
- 活动报名审批查看：进行实时的审批进度结果查询；
- 活动分组查询：对招生活动，学生可查看当前自己所属的分组，该分组当前规则是按照招生对象——学校进行分组；
- 活动反馈查看：当报名审批通过后，可进行各类工作反馈内容查看，其反馈内容可来自以自身、组内成员、领导等；
- 附件上传和下载：可进行可进行附件的上传和下载，附件支持PDF、word、excle等；

#### 1.1.5 活动反馈

当学生报名审批通过后，按照当前活动的创建设置的要求，按照规则如：到达指定时间点，学生进行工作反馈的提交。其功能点如下：

- 工作内容反馈（总结）：按照活动要求，进行工作内容反馈时，系统提供富文本编辑框，进行文字、图片、链接等方式进行描述；
- 附件上传和下载：在反馈时，可进行可进行附件的上传和下载，附件支持PDF、word、excle、视频等；

### 1.3 学院端

当前学院端，在招生宣传报名系统主要是进行对活动报名者资格的审批和监控。该系统学院端应用将集成到智慧学工系统中。

学院端的登录入口在智慧学工登录界面，在统一身份认证基础上实现单点登录。实现同一套账号体系管理。其功能点如下：

- 登录：按照学校统一身份认证平台的账号体系，进行账号/密码登录，成功登录后，进入学院用户PC端——招生宣传报名系统；
- 忘记密码：在统一身份认证平台授权下，可进行密码找回；

#### 1.3.2 活动列表

由学校招生办创建的活动，学院端用户可以进行全部查看。其功能点如下：

#### 1.3.3 报名审核

学院管理员可以审核本学院内的活动报名，其审核节点的审批是根据活动流程设置和管辖范围共同确定。进入到审批菜单界面，进行对申请的查询和审批操作。其功能点如下：

- 筛选查询：按照系统提供的筛选查询字段，可进行精准筛选出要进行审核的活动/具体人员的申请；
- 审核操作：按照自己管辖范围，和活动创建设置的流程，当流程节点的审批者是当前登录的学院用户且该活动申请者属于自己的管辖范围，可对其进行审批。审批系统将按照活动创建时的规则进行，如人数限定，到审批通过人数超过规定人数时，系统进行相关提示。且系统自动进行分组且系统自动进行分组（如按照招生对象——高中名称），对同组人员将按照其成绩、绩点进行排名。审批主要是进行通过/不通过的结果裁定，审批通过则流程进行流转，审批不通过，则终止该申请；
- 批量审核：可对审批列表中待审批事项进行批量审批操作即批量通过/批量拒绝，以此减少繁重的重复性工作；
- 附件上传和下载：在审批时，可进行可进行附件的上传和下载，附件支持PDF、word、excle、视频等；上传后，相关用户可进行下载查阅。

#### 1.3.4 活动反馈及查看

学院管理员可在该应用内，对自己管辖范围类，用户提交的工作反馈进行查看跟踪和自己填报反馈，其功能点如下：

- 搜索查询：在工作反馈菜单，按照系统设置，进行相关精准搜索操作，搜索结果在结果列表中进行展示；
- 查看：对自己数据权限范围类（管理的成员）的工作反馈，进行查看；
- 下载：学院用户可对工作反馈中的附件进行下载；
- 工作反馈提交：学院用户也按照活动要求（如线下活动总结）对活动工作反馈的填写，填写方式包括：文字、图片及附件上传等。

### 1.4 学校端

学校端由学校管理员进行管理，根据招生宣传报名需求该管理员可由招生办指定老师担任，主要管理工作在PC页面操作。

学校端的登录入口在智慧学工登录界面，在统一身份认证基础上实现单点登录。实现同一套账号体系管理。其功能点如下：

#### 1.4.2 活动列表

由学校招生办创建的活动，学校端用户可以进行全部查看。其功能点如下：

- 筛选查询：按照系统提供的筛选查询字段，可进行精准筛选查询活动；
- Banner(轮播图)：在活动列表界面，顶部进行轮播图的展示，点击可进入到对应的活动详情界面；

#### 1.4.3 活动发布

学校管理员（招生办）进行活动的创建。主要包含活动主题、时间设置、类型、参与报名者的指定、流程配置、活动介绍及bannner(轮播图)的设置等。。具体功能点如下所示：

- 活动基础信息维护：主要包含文字描述，如活动名称、活动简介。支持文字、图片的编辑组合方式；
- 信息字段设置：进行自定义信息收集字段新增和编辑。如新增“招生对象学校”，完成后报名者报名时则需填写自己所愿意去的招生学校名称；
- 时间设置:创建者可自定义时间设置，如：活动起止时间、报名时间等；
- 活动类型设置：设定活动类型，如线下活动、线上活动、校外活动、校内活动等；
- 指定参与人群设置：系统将同步用户中心数据，可按照用户角色、名称、用户组，批量或逐一进行参与人群设置；只有系统指定的参与人群，方可进行报名和参与；
- 流程设置：活动创建时，创建者自定义审批流程，如审批流程指定为：学院审核→学校审核，当以此设置，发布后，报名者进行报名后，系统自动进行流程审批流转、；
- 规则设置：如每一所招生对象指定学生人数和教师人数。指定后，在相关人员进行审批时，系统就会做相对应用的提示；
- 其他规则：主要是系统内置规则，如学生报名后，按照学校进行自动分组；在组内自动按照其成绩、绩点进行排名等；
- Banner（轮播图）：系统支持在板块中进行轮播图展示，用户创建时可进行轮播图的维护，具体包含：图片上传、URL配置。

#### 1.4.4 报名审核

学校用户员按照活动的流程设定进行全校师生报名的申请对应节点审批，其审核节点的审批是根据活动流程设置。进入到审批菜单界面，进行对申请的查询和审批操作。其功能点如下：

- 筛选查询：按照系统提供的筛选查询字段，可进行精准筛选出要进行审核的活动/具体人员的申请；
- 审核操作：按照活动创建设置的流程，当流程节点的审批者是当前登录的学校用户，可对其申请进行审批。审批系统将按照活动创建时的规则进行，如人数限定，到审批通过人数超过规定人数时，系统进行相关提示。且系统自动进行分组（如按照招生对象——高中名称），对同组人员将按照其成绩、绩点进行排名。审批主要是进行通过/不通过的结果裁定，审批通过则流程进行流转，审批不通过，则终止该申请；
- 批量审核：可对审批列表中待审批事项进行批量审批操作即批量通过/批量拒绝，以此减少繁重的重复性工作；
- 附件上传和下载：在审批时，可进行可进行附件的上传和下载，附件支持PDF、word、excle、视频等；上传后，相关用户可进行下载查阅。

#### 1.4.5 活动反馈

学校管理员可在该应用内，对所有活动对应用户提交的工作反馈进行查看跟踪和自己在线填报总结，其功能点如下：

- 搜索查询：在工作反馈菜单，按照系统设置，进行相关精准搜索操作，搜索结果在结果列表中进行展示；
- 查看：全校活动对应的人员提交的的工作反馈，进行查看；
- 下载：学院用户可对工作反馈中的附件进行下载；
- 工作反馈提交：学校（招生办）用户也按照活动要求（如线下活动总结）对活动工作进行在线总结填写，填写方式包括：文字、图片及附件上传等。
